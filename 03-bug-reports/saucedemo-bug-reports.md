## Баг-репорты

### BUG-001. [Список товаров] Все товары отображаются с одним и тем же изображением

- **Окружение:** macOS Tahoe 26.7.1, Chrome 157, saucedemo.com, пользователь `problem_user`
- **Шаги воспроизведения:**
  1. Открыть saucedemo.com
  2. Войти под пользователем `problem_user`
- **Фактический результат:** у всех товаров одинаковое изображение: собака с теннисным мячом
- **Ожидаемый результат:** у каждого товара своё изображение (как у `standard_user`)
- **Серьёзность:** Major
- **Приоритет:** Medium
- **Воспроизводимость:** 3 из 3
- **Приложения:** [`problem_user`](screenshots/bug-001-problem-user.png), [`standard_user` (эталон)](screenshots/bug-001-standard-user.png)

### BUG-002. [Список товаров] Сортировка товаров не применяется ни для одной опции

- **Окружение:** macOS Tahoe 26.7.1, Chrome 157, saucedemo.com, пользователь `problem_user`
- **Шаги воспроизведения:**
  1. Открыть saucedemo.com
  2. Войти под пользователем `problem_user`
  3. В выпадающем списке сортировки по очереди выбрать каждую из опций: Name (Z to A), Price (low to high), Price (high to low), Name (A to Z)
- **Фактический результат:** ни одна опция не применяется: в списке остаётся значение по умолчанию Name (A to Z), данные страницы не обновляются, порядок товаров не меняется
- **Ожидаемый результат:** выбранная опция применяется, список товаров отсортирован согласно ей (как у `standard_user`)
- **Серьёзность:** Major
- **Приоритет:** High
- **Воспроизводимость:** 3 из 3
- **Приложения:** [видео](videos/bug-002.mp4)

### BUG-003. [Оформление заказа] Невозможно заполнить поле «Last Name»

- **Окружение:** macOS Tahoe 26.7.1, Chrome 157, saucedemo.com, пользователь `problem_user`
- **Шаги воспроизведения:**
  1. Открыть saucedemo.com
  2. Войти под пользователем `problem_user`
  3. Добавить в корзину товар «Sauce Labs Backpack»
  4. Перейти в корзину
  5. Нажать «Checkout»
  6. На странице «Checkout: Your Information» в поле First Name ввести `Jane`
  7. В поле Last Name ввести `Newkirk`
  8. Нажать «Continue»
- **Фактический результат:** при вводе в поле Last Name текст не отображается, значение в поле First Name заменяется последним введённым символом (`k`), после нажатия «Continue» показывается сообщение «Error: Last Name is required», оформление заказа блокируется
- **Ожидаемый результат:** в поле Last Name отображается `Newkirk`, значение в поле First Name не меняется, ошибка не показывается, оформление заказа продолжается (как у `standard_user`)
- **Серьёзность:** Critical
- **Приоритет:** High
- **Воспроизводимость:** 3 из 3
- **Приложения:** [видео](videos/bug-003.mp4), [скриншот](screenshots/bug-003.png)
