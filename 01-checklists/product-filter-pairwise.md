## Спецификация (условная)

| Параметр   | Значения                                               |
|------------|--------------------------------------------------------|
| Категория  | Одежда, Обувь, Аксессуары                              |
| Цена       | до 1000, 1000-5000, свыше 5000                         |
| Сортировка | по возрастанию цены, по убыванию цены, по популярности |
| Наличие    | только в наличии, все                                  |

Ожидаемый результат для каждого теста: в списке показаны только товары выбранной категории и диапазона цены, в выбранном порядке, с учётом фильтра наличия. 

Набор сформирован инструментом PICT. Покрытие проверила вручную по таблицам пар: все 45 пар присутствуют.

## Вопросы по требованиям

| ID  | Вопрос                                                                                                                   | Принятое допущение                                                                                                                                  |
|-----|:-------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| В-1 | Границы диапазонов включительные? до 1000 — это <1000 или ≤1000; 1000–5000 включает 1000 и 5000; свыше 5000 — это >5000? | Допущение: до 1000 — это меньше 1000, 1000-5000 включает обе границы.                                                                               |
| В-2 | Сортировка по убыванию/возрастанию цены — сортировка по обычной, акционной или итоговой цене?                               | Допущение: цены сортируются по итоговой цене                                                                                                        |
| В-3 | Как разрешаются равные цены — есть ли вторичный критерий?                                                                | Допущение: равные цены считаются эквивалентными, а их взаимный порядок не специфицирован                                                            |
| В-4 | Критерий "только в наличии" — это остаток > 0, доступность к заказу или исключение предзаказа?                           | Допущение: "только в наличии" - соблюдение одновременно условий (купить и оформить здесь и сейчас): остаток >0, доступен заказу, предзаказ исключен |
| В-5 | Включены ли в критерий "все" отсутствующие, снятые с продажи и товары по предзаказу?                                     | Допущение: "все" - все товары, кроме снятых с продажи, включая отсутствующие и предзаказ                                                            |
| В-6 | Категории Одежда / Обувь / Аксессуары полные и взаимоисключающие?                                                        | Допущение: все категории товаров полные и взаимоисключающие                                                                                         |
| В-7 | Есть ли другие параметры (бренд, размер, цвет, цена со скидкой), которые тоже должны входить в попарное покрытие?        | Допущение: других параметров фильтра нет                                                                                                            |

Граничные значения 999, 1000, 1001, 4999, 5000, 5001 лучше проверить отдельными тестами, в попарный набор они не входят.
